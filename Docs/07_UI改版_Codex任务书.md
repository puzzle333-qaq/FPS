## 1. 最终口径（已拍板，不要再改设计）

- 简洁、少字、无大底板；警告红是整套 HUD 唯一允许的彩色时刻。
- **信息要花动作买**：局内不常驻弹药数字。只有长按 R 检视弹匣时才显示弹匣排和精确剩余。
- **进度必须真实**：切图加载的进度条只读真实加载数据，禁止匀速假进度。
- **加载等待用实时镜头，不用预渲染 CG / MoviePlayer 视频。**
- 无人机只拍厂区外围，不进任何室内、不拍账本房。夜间图挂局内同一套夜视后处理。
- 循环飞到全员就绪为止，没有“至少播满 10 秒”，也没有“第二次进图可跳过”。
- 全员就绪后：从当前位置用 1.5–2s 平滑飞到 WP11 → 1.5s 俯冲到 WP12（3m）→ 切回玩家第一人称，播现有举枪 / Raise 动画，然后解锁输入。用俯冲盖住切点。不要做 0.3s 噪点闪黑（已作废）。
- 伤势人像本版不显示，数据接口保留，左下状态条上方留空位。
- 抬手看表删除（解绑按键、去掉显示；函数先留着，不要删代码）。
- 松开 R 才换弹；按住超过阈值进检视。阈值已经是 `0.35s`，保持可调。
- 敌人不能出现在外围等待镜头里。等切回玩家视角后再生成（或至少外围的要等切回后再出现）。

## 2. 设计令牌（1080p 基准，必须按此落地）

颜色：

| 用途 | 值 |
|---|---|
| 主文字 | `#EDEEF0` |
| 次文字 | `#9BA1A6` |
| 弱文字 | `#5C6165` |
| 底板（仅必要时） | `#0A0B0C` @ 65–80%，禁止渐变 |
| 分隔线 | `#FFFFFF` @ 12%，1px |
| 警告（唯一彩色） | `#C33B2E` |
| 就绪/成功 | `#7FA36B` 低饱和 |

- 无金色。禁止发光、禁止投影堆叠、禁止大面积底板面板。
- 圆角 0 或 2；描边 1px。
- 字号只许：40 / 28 / 20 / 16 / 13 / 12。
- 8 点网格：4 / 8 / 16 / 24 / 32 / 48。安全边距：左右 48、上下 40。
- 英文/数字：Barlow Condensed（项目里没有就先用现有窄体，并在报告里写明缺字体）。中文：思源黑体 SC。不要引入 Rajdhani。
- 标签可做成全大写 / 拉开字距。
- 夜图可读性：统一文字阴影 `#000000` @ 60%，偏移 (0, 1)px，不模糊。弹匣描边用同一套。
- 图标：线性、单色跟随文字色，线宽 1.5px @ 24px 画布，尺寸只用 16 / 20 / 24 / 32。美术图标还没入库时允许占位，尺寸和颜色必须对。

## 4. 要做的事（按顺序，做完一步再做下一步）

### 步骤 1：局内 HUD（先做，见效最快）

1. **左下状态条（常驻）**  
   四项横排，无底板，可加第 2 节规定的文字阴影：荧光棒（图标 + `×N`）、夜视仪、手电、镭射。  
   - 开 = 图标主文字色 + 实心小圆点；关 = 图标弱文字色、无圆点。  
   - 图标 20px，组内间距 8，组间 24，位置左 48 / 下 40。  
   - 切换该项时全亮 300ms 再落回。  
   - 按键提示不要进常驻 HUD。  
   - 在状态条上方留一块空位给以后的伤势人像，这版不要画人像。  
   - 数据源用现有角色/配件状态（夜视、手电、镭射、荧光棒数量），自己去代码里找，不要硬编码假数据。

2. **下中弹匣水位（只在检视时显示）**  
   改 `UMagInspectWidget`（或等价实现），不要另起一套队列。  
   - 只在长按 R 检视期间显示：随检视动画 150ms 淡入；检视动画结束后再留 0.5 秒再淡出。换弹、切枪、任务开始都不显示。  
   - 检视时整排全亮；当前匣下方 12px 精确剩余数字（仅此时有精确数）。  
   - 最左 = 当前匣（框 16×40），其后按队列顺序，队尾 = 最近卸下者。空匣退出队列，图标数量随之减少。  
   - 普通匣框 14×34，中空，描边 1.5px，间距 6，水平居中，底边距 40。  
   - 填充自下而上，高度 = 剩余 / 容量。初版用浅灰半透明 + 顶边 1px 高光线（深色版以后 A/B，本轮不做第二套）。  
   - 当前匣填充 ≤25% 且正在显示时，填充改警告红 `#C33B2E`。  
   - 开火模式（全/半自动）出现在排首上方 12px 小字；不进左下状态条。

3. **下线常驻弹药数字**  
   关掉 `CombatHudKeepAlive` 对 `WBP_ReserveAmmo` / `ReserveAmmo` 的强制显示，并确保右下不再出现 `30 | 5` 这类数字。AP 竖条如果还在，一并下线。

4. **隐藏伤势人像**  
   `UBodyInjuryHud` 不要再加到视口（或加了立刻 Hidden / Collapsed）。类和命中部位数据保留。

5. **去掉看表**  
   不再注册 `WatchIMC` / `WatchAction`，`Input_CheckWatch` 不要再绑键。`CheckWatch()` 和蒙太奇字段保留，但不要再弹屏幕调试时间。

6. **低弹量提醒**：做成设置项，默认关。这轮可以只留开关和空实现，不要默认弹出。

### 步骤 2：切图加载叠加层

### 步骤 3：进图后的实时无人机镜头 + 全员就绪切回

每个客户端在本地播同一条路径（所有人看到的路线一致；切回后是各自的角色视角）。

1. **进图且仍处于 Waiting（以及替换掉原来的 2s Briefing）**：把视角切到无人机相机，沿 WP01–WP10 循环。用 Level Sequence 或等价的样条/时间轴，首尾机位必须接上。输入保持锁定，玩家角色不要在镜头前乱动（必要时先把 pawn 藏在出生点、关掉第一人称网格）。
2. **夜间图**：给这台相机加上局内同一套 NVG 后处理，进游戏后不要跳色。
3. **侦察 HUD 框**（Widget 叠加，不要烧进视频）：左上「侦察画面」标签、滚动坐标/时间戳、轻微噪点 + 扫描线、四角信号格。左下或框内放地图名、目标简报、`等待队友就绪 x/x`（数字用主文字色）。**这一阶段不要进度线。** 美术终版没到之前，先按令牌做一版能用的框。
4. **全员就绪**（沿用 `ReadyOperators` / `Auth_OperatorReady`，文案改为「等待队友就绪」）：
   - 不要再走固定 2 秒 `StartBriefing` 然后立刻 `SpawnHostilesFromLevel`。
   - 从当前循环位置平滑插值飞到 WP11，时长 1.5–2s（北侧最远约 75m，用这个区间，不要瞬间传送）。
   - 再沿 WP11→WP12 俯冲 1.5s。
   - 切到玩家第一人称，播现有 Raise / 举枪动画，结束后解锁输入，任务进入 InProgress。
5. **敌人生成时机**：`SpawnHostilesFromLevel()` 必须等到切回玩家视角之后（建议放在举枪动画开始或切镜完成时）。等待循环和飞向 WP11 / 俯冲期间，外围不能看到敌人。
6. 单人（`ExpectedOperators = 1`）时：本地玩家一就绪就走收尾，不必硬飞完整圈。

建议把镜头控制器做成关卡里可配置的 Actor（路径点可从 CSV 导入或在关卡里放好），第一关 `Lvl_Factory`（或当前工厂关卡名，以工程里实际关卡名为准）接上 `drone_path_lvl1_v3.csv`。

### 步骤 4：自检（必须写进报告）

- PIE 单人：进工厂关 → 黑底加载（进度真实）→ 进图后外围循环镜头 + 夜视 + 「等待队友就绪 1/1」→ 随即飞向 WP11、俯冲、切回第一人称、举枪、能操作。外围等待期间看不到敌人。
