# 美术规范（给 Codex 修复用）· Lvl_Factory_Whitebox

## 0. 硬规则（必须遵守）
- 改地图前先备份 .umap；不删除、不覆盖任何外购资产包里的文件。
- 道具一律按原大小摆放（Scale=1.0），不准用放大或不等比缩放来凑尺寸。只有墙、地板这类模块件可以沿长度方向按 100cm 的整数倍拉伸。
- 碰撞：InteriorKit 的网格用 FBX 自带的 UCX_ 碰撞，不要自动生成。
- 单位为 cm，所有物件吸附到 10cm 网格，模块墙吸附到 100cm 网格；旋转只用 90° 的倍数，确实需要斜放的除外。
- 锅炉白模（SM_Boiler_Blockout，180×300）只能放在锅炉房，不能拿来替代别的东西。

## 1. 层高
- 地面 Z=0；主车间钢走廊的行走面 Z=400，板厚 20；地下室地板 Z=-400，在锅炉房正下方。
- 钢走廊：Catwalk_0 在 X 1400–3800、Y -2600 到 -2100；Catwalk_1 在 X 1400–1700、Y -2100 到 -800。底板用 /Game/Factory 里的 SM_Walkway 原大小拼接。
- 楼梯的顶端和底端必须落在对应楼层的行走面上，误差不超过 2cm。现有楼梯比楼板高出约 57–61（以实测为准）：要么换一段较矮的楼梯，要么在顶端加一段平台，不准把楼梯压扁。
- 栏杆沿走廊外边缘连续布置，端头对齐楼梯口，中间不能断开，也不能悬空。

## 2. 门（BP_FactoryDoor，路径 /Game/InteriorKit/Blueprints/）
- 门洞 110×220；门板 SM_Door_Panel_105（105×5×215，pivot 在合页一侧的底边）；门框 SM_Door_Frame_110（外径 130×24×230）。
- 门框的中心线和墙体厚度的中心线重合，门框外缘压住墙洞边缘，不能露缝，也不能凸出。
- 合页统一装在门框内沿；门朝房间内侧开，走廊一侧的门除外，按关卡设计清单。门锁一侧和顶部各留 5cm 缝。
- 门开到 90° 时不能穿墙，也不能穿过家具；门口 120cm 内保持空地。
- 关门状态下的包围盒约为 110×24×230，Z 从 0 到 230。

## 3. 墙体收口
- 室内墙用 /Game/InteriorKit/Meshes 的 SM_IntWall_*（高 300，厚 20）：拐角用 SM_IntWall_Corner，门洞用 SM_IntWall_Door_200 或 SM_IntWall_DoubleDoor_400。
- 墙和墙首尾相接，不留缝也不重叠；墙脚贴地（Z=楼层面），墙顶接天花板或者顶到厂房结构。
- 每个房间都必须闭合：除了门洞和设计好的窗洞，四周不能有漏口。每个房间都要从顶视图和透视图各查一遍。
- 地下室墙底 Z=-400，墙顶接到一层楼板下沿。

## 4. 资产来源（按区域）
| 区域 | 优先使用 |
|---|---|
| 厂房外壳、车间、仓库、装卸区 | /Game/Factory（墙、屋顶、钢梁、SM_Walkway、楼梯、卷帘门、机器、管道、托盘、集装箱） |
| 室内隔墙、通用门、锅炉、配电柜掩体 | /Game/InteriorKit |
| 财务室、档案室、经理办公室 | /Game/Modern_Abandoned_Office（工位、柜子、书架、白板） |
| 地下室（全黑） | /Game/UndergroundTunnel（管道、挂墙电箱、碎石贴花、铁架）；当掩体的配电柜必须用 InteriorKit 的 |
| 武器、弹药、工具 | /Game/FPS_Controller/Environment |

- industrial_machine：用 Factory 包里的传送带、料斗、电机或泵；需要挡全身的（cover=full）高度要在 160 以上，不够就用 SM_ElecCabinet_Tall 代替。
- cargo_container：用 Factory 包里的集装箱。

## 5. 掩体尺寸
- 挡全身的 160 以上（高配电柜 120×60×200）；挡半身的 90–115（低配电柜 80×60×110）。
- 掩体四周留出 120 的通道；锅炉四周也留 120。

## 6. 灯光（试玩通过后再做，先别动）
- 室外中等偏暗；车间和室内由工作灯照亮；地下室全黑，用来教夜视。
- 原则是“规则写实、手感爽快”：敌人和门必须看得清，不要做成恐怖片那种压抑的氛围。

## 7. 每步修完后的自检
1. 透视剖面截图：分别在 Z=-400、0、400 三个高度截一张。
2. 导出所有物件的包围盒 CSV，确认门口 120 内、出生点 100 内没有东西，所有物件都在自己房间里。
3. 列出改动清单：物件名、改了什么、原因。
