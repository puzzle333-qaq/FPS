# 美术白盒替换与装饰（给 Codex）· Lvl_Factory_Whitebox

地图已能跑通。本轮只做视觉：把灰盒墙换成正式模块，补足厂房外形，按区补装饰。不要回滚 `FactoryRepair_Handoff_20261111.md` 里已经修好的结构、碰撞、门和楼梯。

## 硬规则
- 改图前备份 `.umap`。不要运行旧白盒生成脚本，那会覆盖当前已验证的地图。
- 当前已验证状态以 `.umap` 和 `/Game/LevelRepairs/Factory/` 为准。外购资产不要覆盖。
- 道具一律原尺寸（Scale=1.0），不准放大。只有墙、地板这类模块件可以沿长度按 100cm 整数倍拼接或拉伸。
- 不要改已验收的掩体高度：43 组半身掩体约 80–86cm，用户已确认保留，不要替换或缩放。
- 门口 120cm、出生点 100cm 净距必须保持；新增装饰不要堵门、不要挡住楼梯口。
- 灯光亮度和颜色先不动（上一轮只移动过 FD_094）。材质可以赋已有材质，但不要改灯光参数。

## 阶段 1：换掉灰盒墙（优先）
按区域换，每换完一个房间就检查闭合和门洞，再换下一间。

| 区域 | 用什么 |
|---|---|
| 主车间、仓库、装卸区、厂房外壳 | `/Game/Factory` 的墙、窗墙、屋顶、钢梁、门框 |
| 财务室、档案室、经理办公室，以及其它室内隔墙 | `/Game/InteriorKit/Meshes` 的 `SM_IntWall_*`（高 300、厚 20），拐角用 `SM_IntWall_Corner`，天花板用 `SM_IntCeiling_*` |
| 地下室 | `/Game/UndergroundTunnel` 的混凝土/隧道墙；墙底 Z=-400，墙顶接到一层楼板下沿 |

门洞必须保持 110×220，并与现有 `BP_FactoryDoor` 对齐。上一轮墙端曾各侵入 10cm，已经修过，换墙时不要再把洞口吃掉。门框中心线对齐墙厚中心线，不能露缝，也不能把框撑出墙外。每个房间除门洞和设计好的窗洞外必须闭合，不漏光。

## 阶段 2：补场地建筑
现在厂房外形不够，从外面看还是灰盒。补这些，让它读起来像一座废弃工厂：

- 完整屋顶和外部墙面、窗（不要只做室内隔墙）
- 装卸平台、雨棚、`SM_Delivery` 一类码头
- 围栏、道路、门卫/活动房（Factory 包里的 PortaCabin）
- 外部管线和钢结构，让体量站住

建筑必须落在现有场地范围内，不要挡住 A/B 部署点和既有动线。

## 阶段 3：按区补装饰
在不移动已验收掩体的前提下加密装饰，优先用现成包，不要新做网格。

- 车间和仓库：Factory 包的管道、电缆、托盘、工具、集装箱（已有的不要再互相穿插）
- 三间办公室：`/Game/Modern_Abandoned_Office` 的工位、柜子、书架、白板、纸张和显示器
- 地下室：UndergroundTunnel 的挂墙电箱、管道、碎石贴花、铁架；当掩体用的配电柜仍然只用 InteriorKit 的 `SM_ElecCabinet_Tall/Low`
- `industrial_machine` 继续用传送带、料斗、电机或泵；需要挡全身却不够 160cm 的，用 `SM_ElecCabinet_Tall`，不要放大，也不要用锅炉白模去顶

## 做完后的自检
1. 透视下检查：室外能看出厂房，室内墙不再是灰盒，房间不漏光。
2. 门还能正常开合到 90°，开门不穿墙、不穿家具。
3. 楼梯口、走廊护栏、井口护栏仍然连续、可通行。
4. 导出摆设包围盒，确认门口 120cm、出生点 100cm 净距没有被新装饰破坏。
5. 给出改动清单：物件名、改了什么、原因；并附俯视和关键房间透视截图。
