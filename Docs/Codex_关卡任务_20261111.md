## 任务 A：室内加密度（先做）

先读 `06_室内加密度.md`，再按 CSV 和 `factory_dressing_density_v1.md` 摆。只新增，不改已有变换。

CSV 已加 `mesh` 列，按美术对照填写。没有 `mesh` 的行，在对应资产包里选尺寸接近的网格，保持 cover 类型，不要缩放。墙柜若实际是落地柜，放地面靠墙，不要悬空。

**冻结、不要动：** 已验收的门、楼梯、钢走廊、43 组半身掩体（约 80–86cm）；账本柜 `LedgerCabinet_L1/L2/L3`（不要换网格，正前方 ≥100cm）；工作台 W1/W2/W3、料斗、已有货架和集装箱只在旁边补，不要平移。

**间距：** 地面实心物件离布局门洞中心 ≥120cm（含 E1），离出生/刷怪点 ≥100cm，离墙 ≥10cm，通道净宽 ≥110cm。全身掩体高度必须 ≥160cm，不够高用 InteriorKit 的 `SM_ElecCabinet_Tall`，不准放大，也不要用锅炉白模。

### 操作顺序

1. 备份地图。
2. **第一轮只摆地面到 2m 的物件和墙面挂件**（purpose 为 `cover` / `decor` / `desk_clutter` / `wall_hang` / `decal`）。不要在这一轮里加管、接管或改现有管道。办公室九间、厂房沿墙/柱脚、地下室铁架和挂墙电箱都在这一轮完成。
3. **第二轮单独接管：** 第一轮完成后再接五条连续管路（purpose 为 `pipe` / `pipe_fit`）。2m 管按原尺寸阵列，轴心在一端，禁止拉伸。对不齐的空隙用短接或管件。不要和第一轮混在一次改图里。五条管路细节见 `factory_dressing_density_v1.md`。
4. 导出包围盒，用 `qa_factory_dressing.py` 按真实包围盒复查。门口 120cm、出生点 100cm 告警必须为 0。已有门、楼梯、掩体的变换不能被改动。
5. 按 06 的自检截图：财务室、档案室、经理室、主车间、地下室，另补前台、开放办公室、货物仓。车间和地下室至少拍到一条从头接到设备的管路。

## 任务 B：无人机等待镜头（实时镜头，不要预渲染视频）

用 Level Sequence（或等价的运行时相机）按 `drone_path_lvl1_v3.csv` 飞。夜间图直接挂局内夜视后处理，与进游戏后的 NVG 一致。

CSV 列：`id,time_s,X_cm,Y_cm,Z_cm,segment,area,note`。

- **循环段** `segment=loop`：WP01–WP10，一圈 13.5 秒，绕厂区外围四面。WP10 与 WP01 坐标相同，首尾相接，无缝循环。全程室外，不进任何门，不拍办公区内部和三间账本房（财务室 / 档案室 / 经理室）。E1 卷帘门只在门外对准，不穿门。
- 没就绪就一直循环。10 秒不再是最短播放时长。
- **收尾段** `segment=end`：全员就绪后，从循环上的当前位置平滑插值到 WP11（部署点 A 上空，X=4400，Y=2000，Z=1800），再 **1.5 秒俯冲** 到 WP12（X=4400，Y=800，Z=300）。然后接 0.3 秒夜视噪点 + 黑帧，切回各客户端玩家第一人称，播举枪动画后解锁输入。
- 过渡到 WP11 的时长不固定，按距离实时插值，不要穿外围碰撞。循环段离 WP11 最远约在北侧，大约 75m，这段过渡建议 1.5–2 秒。
- **敌人：** 等待画面不要拍到外围巡逻。切回玩家视角后再显示外围敌人，或等待期间只生成室内敌人。

镜头朝向：循环段大致沿前进方向看，经过 E1 时短暂对准卷帘门；俯冲段看向部署点 A 地面。不要穿过外墙或围栏。
