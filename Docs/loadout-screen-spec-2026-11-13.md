# 装备画面设计文档（参考 P2 / P3）

定稿日期：2026-11-13。参考图 P2（英文原版）与 P3（中文本地化）是同一界面的总览页与武器详情页，学结构不抄皮。通用令牌沿用《UI 最终方案》，本文只写本屏特有部分。

**定位先说清：这不是新系统，是现有配装台的全屏重构。** 触发点不变（靶场大厅配装台 `ARangeLoadoutBench` 交互打开），数据与存档不变：武器与附件走 `UGunsmithComponent` + `UAttachmentData`，弹药槽位走 `UPouchInventoryComponent`（硬数据：共 **13 个槽位**，每格 `FPouchSlot` 带武器类型与发数），预设存 `UWarehouseLoadoutSaveGame`，右侧角色预览已有 `ALoadoutPreviewRig`。要换的只有呈现层（现行 `URangeLoadoutWidget`）。

## 一、参考拆解（P2/P3 为什么成立）

- **左窄右宽**：左侧约 1/3 是操作区（列表），右侧 2/3 只做一件事——全身角色预览。玩家改任何一件装备，右边的人立刻变，“配装”因此有实体感。
- **分组即目录**：WEAPONS / ARMOR & MUNITIONS / HEADWEAR 大写分组标题 + 细分割线，信息再多也不乱。
- **槽位是实体不是数字**：弹药用一排真实弹匣图标表示，13 格占满就是占满，不用读文字。
- **武器详情是“下钻”不是新页**（P3）：点武器进入附件列表（光学/枪口/下挂/上挂/其他/照明），底部切到弹药/部署物，角色手中的武器同步换装。
- 红色仍然只有两类用途：当前选中标记与占满/超限警告；外加场景里角色的红色轮廓光——那是灯光不是 UI 色。

## 二、总览页布局（1920×1080，边距 48/40）

左栏宽 620，从上到下：

| 区 | 内容 |
|---|---|
| 页签行 | 「火力配置 / 定制」28px，当前页签下 2px 红线。定制页（外观）若当前无数据，第一版只留火力配置单页，页签行隐藏 |
| 操作员行 | 当前查看的队员名（SELF/队员名）20px 居中，两侧细线。联机时可左右切换查看队友配装（只读，见 §五） |
| 预设行 | 小标 PRESET 13px + 预设名下拉 20px + 右侧保存图标按钮 32×32。有未保存改动时预设名后加一个红点 |
| WEAPONS 组 | 三行：主武器 / 副武器 / 战术装备。每行：武器渲染图 高 84（左）+ 类型小标 12px + 武器名 28px；行高 120，分隔线 1px 12% 白 |
| ARMOR & MUNITIONS 组 | 防具行（小图 + 名称，右侧两格属性：材质 / 覆盖，见 §四的待确认项）+ 弹药槽位行（见 §三） |
| HEADWEAR 组 | 头盔行：小图 + 名称，右侧两格：挂载（夜视仪）/ 面部（面罩）。夜视仪是本作标志装备，挂载格不可为空缺省——默认「夜视仪」 |

右区（x 约 700–1872）：角色预览。黑色背景，角色立于画面右侧三分线，红色轮廓光来自场景灯光设置（PreviewRig 的灯光预设），UI 层不叠任何面板；底部右对齐一行小字 13px 次级色显示总槽位占用「11/13 槽位」（与左栏弹药行同步）。

## 三、弹药槽位（本屏与全游戏的一致性关键）

- 13 个槽位 1:1 对应 `UPouchInventoryComponent::SlotCount`。每格 18×44 的弹匣形图标：横排呈现，按归属武器分组（主武器弹匣组 / 副武器弹匣组），组间空 16，下方标弹种小字（AP/JHP——**仅当 WeaponData 已有弹种数据时显示**，没有则只标数量，这是待确认项，见 §六）。
- 分配方式：每组右侧 `< N >` 步进器（P3 式），加减即增减该武器的满弹匣格数。
- **图标语言与局内 HUD 统一**：这里的弹匣图标 = 长按 R 检视时底部中央出现的那排“水位弹匣”同款外形——玩家在配装时分配的格数，就是进游戏后弹匣队列的长度，一眼对得上。
- 校验：总占用 = 13 时计数变红（占满提示，非错误）；投掷物/部署物也占格时一并计数，超限时步进器 + 号置灰并轻微抖动一次。
- 空格呈现：只画空框（1.5px 描边），不填充。

## 四、武器详情页（P3 式下钻）

点总览页任意武器行进入，左栏切换为：

- 顶部：武器名 40px + 类型小标；其下一条“已装备”状态条（就绪绿 `#7FA36B` 4px 高亮段 + 文字），仅当前出战武器有此条。
- 页签：主武器 / 随身武器（在本页内横切两把枪），当前页签红下划线。
- **附件列表**（数据出 `UAttachmentData`，槽位顺序固定）：光学瞄具 / 枪口 / 枪管下 / 枪管上 / 其他设备 / 照明器。每行：附件渲染图 96×40 + 部位小标 12px + 附件名 20px；行高 72。点击行 → 该行下方展开横向候选条（同槽全部附件缩略图，当前项红线标记），点选即换、预览武器同步。这一行展开式比跳转新页快，也和参考图 P3 的纵向列表一致。
- 底部页签：**弹药 / 可部署物品**。弹药页即 §三 的分组步进器（限当前武器）；可部署物品页为投掷物与装备的计数步进（闪光等已实装项），同样占 13 格总池。
- 返回：Esc 或顶部返回区回到总览，改动即时写入当前预设（未保存状态点亮预设行红点）。

## 五、联机与权限

- 本屏在靶场大厅打开，天然是部署前环节：改的永远是**自己**的配装。
- 操作员行切换到队友时进入只读：所有步进器与附件行置灰，标题旁标 13px「只读 · 队友配装」。查看队友配装对配合分工有用（谁带破门、谁弹药多），但绝不能替人改。
- 预设是本地存档（WarehouseLoadoutSaveGame），不跨玩家同步；进图时以各位玩家自己的当前配装为准。

## 六、待确认项（动工前先核这三件）

1. **防具数值**：仓库里没核到防具的材质/覆盖数据结构。若当前版本防具只是外观，防具行第一版只做选择+预览，属性两格留空隐藏，等数值系统有了再点亮——不要为了版式编数据。
2. **弹种（AP/JHP）**：P2/P3 都有，本项目 WeaponData 是否有弹种/伤害类型字段未核实。有才显示弹种小标与分弹种计数；没有就只做“弹匣格数”一层。
3. **定制（外观）页**：P2 有 CUSTOMIZATION 页签。若当前没有外观系统，第一版不做此页，页签行隐藏，避免空页签。

## 七、落地顺序

1. 全屏骨架 + PreviewRig 角色与红轮廓光预设，假数据跑通总览页版式。
2. 武器行与详情页接 Gunsmith 数据（附件换装实时上预览武器）。
3. 弹药槽位接 Pouch 组件，与 HUD 弹匣队列图标统一素材。
4. 预设存取（WarehouseLoadoutSaveGame）与未保存红点。
5. 队友只读查看。
6. §六 三项确认后再决定防具属性格、弹种层、外观页是否点亮。
