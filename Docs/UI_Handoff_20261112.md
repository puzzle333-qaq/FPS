# UI 改版 Codex 任务书（2026-11-12）

项目：Co-op CQB FPS（UE 5.8）  
地图：`/Game/Maps/Lvl_Factory_Whitebox`  
范围：加载流程 + 局内 HUD。主菜单、配装、结算不做。  
本文是执行口径。与群里 2026-11-12「UI 改版方案（定稿）」冲突时，以本文为准。

配套文件：`drone_path_lvl1_v3.csv`（只用 v3，v1 / v2 作废）。

---

## 0. 硬性规则

1. 改任何 Widget、输入、关卡序列前，先备份到 `Saved\`，写上时间戳。代码先备份再改，不要直接删。
2. 不新增动画资产。只用现有举枪（Raise）、检视弹匣、门机制。
3. 进度只读真实数据，禁止匀速假进度。宁可停住，也不爬到 99% 演戏。
4. 局内不常驻弹药数字。想看弹量，必须长按 R 检视。不为“方便”破例。
5. 无人机是图内实时镜头，不预渲染视频，不走 MoviePlayer 播 CG。
6. 镜头只拍厂区外围，不进任何室内，不拍三间账本房和办公区内部。
7. **无人机画面不得暴露敌人位置。** 切回玩家并解锁输入之前，外围敌人不可见（先不生成，或生成但隐藏）。室内敌人可以先生成，因为镜头不进室内。
8. 一次只改一类，改完自验再做下一类。

## 1. 设计令牌（1080p 基准）

### 颜色

| 用途 | 值 |
|---|---|
| 主文字 | `#EDEEF0` |
| 次文字 | `#9BA1A6` |
| 弱文字 | `#5C6165` |
| 底板（仅必要时） | `#0A0B0C` @ 65–80%，禁止渐变 |
| 分隔线 | `#FFFFFF` @ 12%，1px |
| 警告（唯一允许的颜色时刻） | `#C33B2E` |
| 就绪/成功 | `#7FA36B` 低饱和 |

金色退出常驻 UI，默认不用。

### 字体与字号

- 英文/数字：只许 Barlow Condensed。中文：思源黑体 SC。禁止系统默认字体出货，不要再用 Rajdhani。
- 标签：全大写 + 拉开字距（中文用加空格/字距近似）。
- 字号只许 6 档：40 / 28 / 20 / 16 / 13 / 12。

### 间距、形状、可读性

- 8 点网格：4 / 8 / 16 / 24 / 32 / 48。
- 屏幕安全边距：左右 48、上下 40。
- 圆角 0 或 2；描边 1px；禁止发光、禁止投影堆叠、禁止大面积底板面板。
- 夜间可读性统一用文字阴影：`#000` @ 60%，偏移 0/1px，不模糊。弹匣描边用同一套。验收截图必须覆盖三种底：夜视、手电直射墙面、全黑。

### 图标

- 全套线性图标，单色跟随文字色，线宽 1.5px @ 24px 画布，尺寸只用 16 / 20 / 24 / 32。
- 美术图标尚未入库。先按上述规格用占位图标接通，路径预留 `FPS\Docs\UI`，到了再替换。

## 2. 加载与等待（实时镜头）

分两段，不要做成预渲染 CG。

### 2.1 切图加载（地图还没进来）

- 黑底。
- 左下（48 / 40）：标签 `行动准备` 13px 次文字色；任务名 20px 主文字色（第一关用 `清剿行动 — 清光匪徒`，可配置）。
- 底部：全宽 2px 进度线，填充主文字色 @80%，无圆角、无百分比数字。进度只反映关卡流送/异步加载真实完成度。
- 右下：状态文案 `正在部署…` 16px。停滞超过 5 秒，文案尾加省略号动画表示进程存活。
- 不要视频，不要旧的中央浅灰面板（行动准备 / SQUAD LOADING 整体废弃）。

### 2.2 进图后等待（等队友 / 等准备）

- 每个客户端把视角切到沿 `drone_path_lvl1_v3.csv` 循环段飞行的相机（Level Sequence）。
- 夜间图直接挂局内夜视后处理，进游戏后不得跳色。
- 路径是闭环：循环段 13.5 秒绕外围四面一整圈，WP10 = WP01，没准备完就一直转。坐标单位 cm，Z 向上。

循环段路点（segment=`loop`）：

| id | time_s | X | Y | Z | 备注 |
|---|---|---|---|---|---|
| WP01 | 0.0 | -1000 | -4800 | 1800 | 循环起点=终点，西北角 |
| WP02 | 1.5 | -1000 | -2000 | 1600 | 西侧向南 |
| WP03 | 3.0 | -800 | 800 | 1300 | 西南角，掠过部署点 B / E2 |
| WP04 | 4.5 | 2000 | 1200 | 1100 | 南侧，掠过撤离点 X1 |
| WP05 | 6.0 | 4400 | 1200 | 900 | 对准 E1 卷帘门，不进门 |
| WP06 | 7.0 | 6400 | 0 | 1200 | 东南角，绕过调度室外侧 |
| WP07 | 8.5 | 6600 | -3000 | 1500 | 东侧向北 |
| WP08 | 10.0 | 6000 | -5200 | 1800 | 东北角 |
| WP09 | 12.0 | 2500 | -5400 | 1800 | 北侧向西 |
| WP10 | 13.5 | -1000 | -4800 | 1800 | 回到 WP01，无缝循环 |

- 侦察 HUD 框（Widget 叠加，不烧进画面）：地图名、目标简报、`等待队友就绪 x/x`（数字用主文字色）。**不要进度线。** 夜视绿底上框线必要时压到 `#9BA1A6`。
- 文案禁词：流送、加载（对玩家用“部署”）、生成、禁止、判定。
- 已作废：至少播满 10 秒、第二次进图可跳过、预渲染 CG、收尾片段切视频。

### 2.3 全员就绪后切回玩家

只有一个收尾点，不要找“最近收尾点”。

| id | time_s | X | Y | Z | 备注 |
|---|---|---|---|---|---|
| WP11 | 0.0 | 4400 | 2000 | 1800 | 部署点 A 上空 18m |
| WP12 | 1.5 | 4400 | 800 | 300 | 俯冲到 3m |

流程：

1. 服务器通知所有客户端：全员已就绪。
2. 从当前循环位置实时插值飞到 WP11。外围最远约在北侧 75m，这段给 1.5–2 秒，按距离插值，外围不得穿帮。
3. 再俯冲 1.5 秒到 WP12（3m）。
4. 接 0.3 秒夜视噪点 + 黑帧（无人机断信号）。
5. 切回各自角色的第一人称，播放现有举枪动画，播完解锁输入，行动开始。

卷帘门开口和集装箱实际位置，在 Sequencer 里对一下路径，必要时只微调 XY，不要改“只拍外围、不进门”这条。

## 3. 局内 HUD

### 3.1 左下状态条（常驻）

横排四项，无底板，可用文字阴影保可读性。位置左 48 / 下 40。图标 20px，组内间距 8，组间 24。

| 项 | 形式 |
|---|---|
| 荧光棒 | 线性图标 + `×N` |
| 夜视仪 | 图标 + 状态 |
| 手电 | 图标 + 状态 |
| 镭射 | 图标 + 状态 |

- 开 = 图标主文字色 + 实心小圆点；关 = 图标弱文字色、无圆点。不用文字表示开关。
- 切换时该项全亮 300ms 再落回。
- 按键提示永不进常驻 HUD，只随情境提示（交互等）临时出现。
- **伤势人像：这版不做。** 从现有 HUD 上隐藏，数据接口保留。在状态条上方留空位，以后再接。不要删代码。
- **抬手看表：删掉。** 解绑按键，拿掉这部分 HUD，代码备份后先不删。
- 无线电字幕、血迹效果开关：本轮不做。

### 3.2 下中弹匣水位（只在检视时显示）

- 只在长按 R 检视弹匣期间显示：随检视动画淡入 150ms，动画结束后留 0.5 秒淡出。换弹、切枪、任务开始均不显示。
- 检视期间给全信息：整排全亮；当前弹匣下方出现 12px 精确剩余数字。仅检视时有精确数。
- 低弹量提醒做成设置项，默认关。

**R 键判定（已拍板）：**

- 松开 R 才触发换弹。
- 按住超过约 0.35 秒进入检视。阈值做成可调。先核对现有代码阈值，再改，避免 CQB 中途误换弹。

**队列（先核对现有换弹逻辑，不是队列要先改游戏逻辑再画 HUD）：**

- 换弹取队首下一个，卸下的弹匣（含半弹匣）回队尾保留。
- 图标最左 = 当前弹匣（16×40），其后按接下来的顺序，队尾 = 最近卸下者。
- 空弹匣退出队列（检视时图标数减少）。

**图标规格：**

- 框 14×34px（当前 16×40），中空，描边 1.5px，间距 6；屏幕下中，底边距 40。
- 填充自下而上，高度 = 剩余弹量 / 容量。
- 初版用浅灰半透明 + 水位顶边 1px 高光线。深色填充做一版 A/B，三种底上截图对比后回填，先不要锁死。
- 当前弹匣填充 ≤25% 且处于检视显示时，填充转警告红——整套 HUD 唯一允许的颜色时刻。
- 开火模式（全/半自动）随弹匣排出现，置于排首上方 12px 小字；不进左下状态条。

### 3.3 其他局内元素

- 原右下角常驻数字弹药（30 | 5）以及 AP 竖条弹匣：下线。
- 交互提示：准星下方，只出现当前可执行的一个动作 + 键帽（底 `#1A1C1E`、字 `#EDEEF0`、圆角 2、内边距 6/2，禁止金色键帽）。
- 目标/任务提示、队友名牌、伤害反馈：位置不动，只换第 1 节令牌样式，不改结构。

## 4. 实施顺序（严格按此执行）

1. **核对弹匣队列与 R 键阈值**，再改输入：松开 R 换弹，长按进入检视。
2. **局内 HUD**（纯 UMG/Widget）：状态条 → 弹匣排（接队列 + 检视显隐）→ 下线右下数字弹药和 AP 竖条 → 隐藏伤势人像并留位 → 看表解绑并拿掉 HUD。
3. **加载叠加层**：删旧浅灰面板；落地切图黑底 + 左下/底部进度线/右下文案；进图等待换成侦察框（地图名、简报、等待 x/x，无进度线）。
4. **实时无人机镜头**：按 v3 摆 Level Sequence 循环路径；夜间挂局内夜视后处理；就绪后插值到 WP11 → 俯冲到 WP12 → 0.3s 噪点黑帧 → 切第一人称 → 举枪 → 解锁输入。同时落实第 0.7 条（外围敌人不可见）。
5. **联机验证**：双人测早到/晚到各一遍；检视显隐、队列轮转与图标一致；R 键不误换弹。
6. **打包验证**：Development + Shipping 各跑一遍加载全流程（打包版与 PIE 行为不同，必须实测）。

## 5. 验收

- [ ] 切图加载只有黑底、任务名和真实进度线，没有假进度、没有旧面板
- [ ] 进图后镜头只沿外围循环，不进室内、不拍账本房，夜视色调与局内一致
- [ ] 未全员就绪时一直循环，不提前切走，也不强制播满固定秒数
- [ ] 全员就绪后：飞到部署点 A 上空 → 俯冲 → 断信号 → 第一人称举枪 → 解锁输入
- [ ] 外围敌人在解锁前不可见
- [ ] 左下只有四项状态，无底板，夜视/手电/全黑三种底都可读
- [ ] 弹药数字与水位只在长按 R 检视时出现；松开 R 才换弹；短按不会误检视
- [ ] 右下常驻弹药和 AP 竖条已下线
- [ ] 伤势人像已隐藏但接口还在，状态条上方留了空位
- [ ] 看表已解绑、HUD 已拿掉，代码还在
- [ ] Development 与 Shipping 打包各通过一遍

## 6. 本轮不做

- 主菜单、配装、结算
- 预渲染加载 CG、MoviePlayer 播绕图视频
- 伤势人像出图、抬手看表、无线电字幕、血迹开关
- 室内加密度和管道（那是另一份任务书）。注意：实时镜头会拍到外围，外墙、地面、围栏的美化应与室内加密度同步或提前，否则等待画面全是白盒；本任务书不负责摆这些物件，但不要覆盖或回退已有外围改动。
