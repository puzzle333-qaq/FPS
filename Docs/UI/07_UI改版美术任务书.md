1. 从循环上的当前位置，平滑飞到 WP11（部署点 A 上空 18m）。这段由程序按距离插值，时长不固定，外围不要穿模。

敌人不要出现在等待画面里：外围巡逻等切回玩家视角后再显示，或先只生成在室内。默认按前者做。

## 3. 视觉规格（令牌）

### 颜色

| 用途 | 值 |
|---|---|
| 主文字 / 开启态图标 | `#EDEEF0` |
| 次要文字、必要时的框线 | `#9BA1A6` |
| 弱文字 | `#5C6165` |
| 面板 | `#0A0B0C`，透明度 65–80% |
| 分割线 | 白，12% 不透明度 |
| 警告（唯一彩色强调） | `#C33B2E` |
| 就绪 | `#7FA36B` |
| 键帽底 | `#1A1C1E` |

### 字体

只准这一套：拉丁和数字用 Barlow Condensed，中文用思源黑体（Source Han Sans SC）。两款都是 OFL，可以进包。不要再引入第三款字体。

字号只准这六档：40 / 28 / 20 / 16 / 13 / 12。

### 布局

- 8pt 网格。安全边距左右 48、上下 40。
- 圆角 0–2px，描边 1px。
- 图标：24px 画布、1.5px 线性描边，导出尺寸 16 / 20 / 24 / 32。

### 夜视/夜间可读性

所有叠在实景或夜视画面上的文字、弹匣描边，统一加一层文字阴影：`#000000`、不透明度 60%、偏移 X=0 Y=1、不模糊。不要外发光。需要的话对夜视、手电眩光、全暗三档做一次对照。

- 键帽：底色 `#1A1C1E`，线性图标，不要拟物、不要发光。
