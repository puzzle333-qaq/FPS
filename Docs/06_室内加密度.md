# 室内加密度（给 Codex）· Lvl_Factory_Whitebox

墙面材质和外围已经过了。本轮只补房间和厂房的地面、墙面和连续管线，不要改已经验收的门、楼梯、钢走廊和掩体。坐标和数量以 `FPS\Docs\factory_dressing_density_v1.csv` 为准，本文件管视觉接法和用什么资产。

## 问题
上一轮 Stage3 的 164 件装饰大部分没有填到人能看见的高度：
- 主车间、货物仓、零件库、弹药间、改装间、组装间、锅炉房、装卸平台：几乎全是 Z=253–630 的短段高位管道和电缆，没有接成管路，地面和墙面仍然空。
- 财务室、档案室、经理室：各只加了 6–8 件桌面纸张、杯子、白板或一个书架。
- 前台、会议室、开放办公室、休息室、调度室、办公走廊：Stage3 一件都没加。
- 地下室同样偏空。

## 硬规则
- 改图前备份 `.umap`。不要跑旧白盒生成脚本，不要覆盖外购资产。
- 全部原尺寸（Scale=1.0），不准放大。
- 不要移动、替换或缩放已有掩体（含用户批准的 43 组 80–86cm 半身掩体）。
- 门口 120cm、出生/刷怪/撤离点 100cm 净距必须保持；不要挡住楼梯口和钢走廊通道。
- 灯光亮度和颜色先不动。
- 优先补地面到 200cm 的视线高度，以及墙面挂件。不要再单独摆一段不接头的 4m 管道。

## 管道必须接成管路
现有短段管道要接到能看懂的线路上，不要再加孤立短管。
- 厂房用 `/Game/Factory` 的大/中/小管及弯头、三通、阀门、管卡；地下室用 `/Game/UndergroundTunnel` 的管道和接头。
- 每一段都要有起点和终点：设备、水箱/锅炉、墙洞或竖井，用弯头和三通转弯，用管卡或托架贴墙、贴梁，管口用管帽收住。
- 沿梁或沿墙走，高度可以超过 200cm，但必须是连续管路的一部分，不能悬空、不能刺穿已验收的楼梯和门框。
- 接到现有设备上时，对准接口，不要穿进机体。

## 墙面不能再空
大块空墙要挂东西，避开窗洞和门框：
- 厂房和地下室：线槽、管道支架、阀门、挂墙电箱、警示牌。地下室的挂墙电箱用 UndergroundTunnel 的；当掩体用的落地配电柜仍然只用 InteriorKit 的 `SM_ElecCabinet_Tall/Low`。
- 办公室：书架、白板、公告、线槽或挂柜，把空墙打断。
- 墙面挂件贴墙，不要浮在墙外，也不要打进墙里。

## 办公室（用 /Game/Modern_Abandoned_Office）
把下面这些房间都补到“走进去不像空房间”：财务室、档案室、经理室、前台、会议室、开放办公室、休息室、调度室、办公走廊。

每间至少再补：
- 沿墙的柜子、书架或纸箱，打破大块空墙
- 桌面杂物：键盘、显示器、托盘、散纸、杯子、书（账本柜本身不要换、不要挡住，必须仍能认出来）
- 角落的纸箱、打印机、植物或垃圾桶
- 休息室可加班发、茶几、杂志；会议室加桌椅和白板；开放办公室补工位，不要只放一两张空桌

## 厂房地面（用 /Game/Factory，其次 /Game/FPS_Controller/Environment）
主车间、货物仓、零件库、弹药间、改装间、组装间、锅炉房、装卸平台，沿墙和柱脚加密，中间留出战斗通道。

补这些视线高度的物件：
- 成组的托盘、木箱、油桶、集装箱（不要互相穿插）
- 工具车、工具箱、工作台
- 原尺寸的传送带、料斗、电机、泵；需要挡全身却不够 160cm 的，用 `SM_ElecCabinet_Tall`，不要放大，也不要用锅炉白模
- 墙边的线盘、零件箱、靠墙码放的板材

主车间中央那片空地不要铺满，保留穿行和掩体周围 120cm 通道；空感主要靠墙边、柱边的成组堆放和墙面挂件来压住。

## 地下室（用 /Game/UndergroundTunnel）
泵房、配电室、楼梯间必须和上面房间一起填，不要放到最后才补。地面加铁架和杂物，墙面加电箱、碎石贴花和靠墙管道，管道同样要接成连续管路。


## 类型名对照（361 件表里的 asset_hint）
表里不少是类型名，不是网格原名。按下表在对应包里选，一律 Scale=1.0，不要为了凑假定尺寸去缩放。找不到再在同一包里挑最接近 SIZE 表的网格。

厂房管路（与表里的 `SM_L_Pipe_2m_01` 同一套 Large，路径 `/Game/Factory/Static_Mesh/Pipes/Large/`）：
- `pipe_elbow` → `SM_L_Pipe_Bend`（直角不够再试 `SM_L_Pipe_BendVar`）
- `pipe_tee` → `SM_L_Pipe_TJunction`
- `pipe_cap` → `SM_L_Pipe_Terminal`
- `pipe_clamp` → 没有独立管卡，用 `SM_L_Pipe_Joint` 贴墙或贴梁
- 20–80cm 空隙用 `SM_L_Pipe_1m_01` / `SM_L_Pipe_1m_02` 或管件补，禁止拉伸 2m 管，也不要再加孤立 4m 管

地下室管路（与 `SM_Pipe02a_2m` 同一套，`/Game/UndergroundTunnel/Meshes/Props/`）：
- `pipe_elbow_ut` → `SM_Pipe02a_joint_90elbow`（或 `_B`）
- `pipe_cap_ut` → `SM_Pipe02a_cap`
- `pipe_clamp_ut` → `SM_Pipe02a_bracket_A`
- 短空隙用 `SM_Pipe02a_50cm` 或 `SM_Pipe02a_1m`

厂房地面和墙面：
- `wooden_crate` → Factory `SM_CargoCrate_01` 或 `SM_CargoCrate_02`
- `pump` → Factory `SM_Gas_Pump`，不要用料斗或 `SM_Machinery_MainBlock`
- `motor` → Factory `SM_MotorBase`；看起来缺件时在同一位置再加 `SM_MotorHead_01`，仍不缩放

- `sheet_stack` → Factory 没有板材堆，改用 FPS `SM_Planks_01`（或 02/03 里最接近的）
- `warning_sign` → Factory 贴花 `SM_Caution_01_Decal`，不要用室外 `SM_RoadSign`；地下室可改用 UndergroundTunnel 的 `SM_Sign01a` 等标牌
- `cable_tray_factory` 和办公走廊的 `cable_tray_2m`：这两个包都没有线槽，改用 FPS `SM_CableTray` 原尺寸阵列，转弯用 `SM_CableTray_LeftTurn` / `RightTurn`

FPS_Controller：
- `tool_cart` → `SM_PlatformCart`
- `parts_box` → 接近 40×35×30 的 `SM_Wooden_Box_01` 或 `SM_Crate`，不要用 `SM_BigBox`
- `wall_tools` → 没有整块工具挂板，用 `SM_Wrench`、`SM_Hammer`、`SM_Screwdriver` 贴墙成组

办公室（`/Game/Modern_Abandoned_Office/Static_Meshes/`）：
- `cardboard_box` → `SM_box_01`（可换 02–04 或 `SM_box_top_01`）
- `keyboard` → `SM_Keyboard_01`；`paper_stack` → `SM_Sheets_01`；`coffee_mug` → `SM_Cup`；`books` → `SM_Book_01`；`magazine` → `SM_Magazine_01`；`printer` → `SM_printer`

- `wall_cabinet` → `SM_Cabinet`、`SM_Cabinet_001`、`SM_Shelf_01` 里进深最浅的；若是落地柜，把 Z 改到地面靠墙，不要挂在 140cm 悬空
