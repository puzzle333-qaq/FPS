## 5. 无头运行（编辑器关闭时）
UnrealEditor-Cmd.exe "<uproject>" -unattended -nop4 -nosplash -NullRHI -stdout -FullStdOutLogOutput -ExecutePythonScript=<脚本>
（用 MCP 连接正在运行的编辑器时就不用这一步；不要同时跑无头和编辑器。）
## 6. MCP 怎么连 UE（已核对 FPS.uproject）
- 工程里已经启用：ModelContextProtocol、AllToolsets（UE 自带的 MCP 插件和工具集）、PythonScriptPlugin、EditorScriptingUtilities
- 打开 UE 编辑器后由插件提供 MCP 服务；端口和地址以编辑器里的插件设置 / 输出日志为准，这里没核对过，请勿写死
- 用 MCP 时编辑器必须开着，这时不要再跑无头 UnrealEditor-Cmd（两边同时改同一张图会冲突）；改完在编辑器里保存地图
- 每次批量修改前，先把地图复制到 Saved\AssetBackup_<时间>_<说明>（或在 MCP 里另存一份 _bak）

## 7. BP_FactoryDoor 参数（父类 /Script/FPS.BreakableDoor）
- DoorLeafMesh = /Game/InteriorKit/Meshes/SM_Door_Panel_105（轴心在合页一侧的底边）
- DoorFrameMesh = /Game/InteriorKit/Meshes/SM_Door_Frame_110（轴心在底部中心）
- 合页位于 (0,-55,0)，门板跨 Y=-55~50；锁舌一侧和顶部各留 5cm 缝
- bSnapLeafToHingeEdge = False；Yaw +90，让门的正面朝 actor 的 X 轴
- 门是双向开的，朝玩家面对的方向打开；往上看推开（慢、安静），往下看踹开（快、响）
- 门 actor 的 Z：地面 0，地下 -400
