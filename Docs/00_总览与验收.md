# Lvl_Factory_Whitebox 修复文档：总览与验收（给 Codex）

## 目标
修复 `/Game/Maps/Lvl_Factory_Whitebox` 白盒问题，让人能从部署点走到拿账本（LedgerCabinet_L1/L2/L3）。只修白盒，不做美化。

## 硬性规则
1. 每次改地图前先备份到 `Saved\` 下，并写明时间戳。
2. 不放大网格。尺寸不对就换别的资产；实在没有，就先用 `/Game/InteriorKit/Meshes/` 里的高配电柜顶上，不用锅炉白模。
3. 不自动生成碰撞，InteriorKit 自带 UCX 碰撞。
4. 单位用 cm，Z 轴向上。每轮改完导出物件的位置和包围盒 CSV，再附一张剖面图或俯视图。
5. 一次只改一类问题，改完跑一遍检查，再改下一类。
