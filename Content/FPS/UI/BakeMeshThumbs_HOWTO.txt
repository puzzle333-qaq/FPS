准备界面缩略图：预烘焙 Texture（不用实时 Scene Capture）
========================================================

运行时只读 Texture2D，不再 Spawn MeshPreviewCapture。
备份：Saved\CodeBackup_20261030_223400_BakedThumbs

----------------------------------------------------------------
WBP 接线
----------------------------------------------------------------
1. WBP_Loadout 父类仍可用 LoadoutMeshThumbnails（或保持不变）。
2. Image 名：MainWeaponImage / PistolWeaponImage / VestImage / MagImage / HelmetImage
3. Class Defaults → FPS|Thumbnails|Textures 填 Soft Texture2D。
   留空默认找：
     /Game/FPS/UI/Thumbs/T_Thumb_RAR
     /Game/FPS/UI/Thumbs/T_Thumb_Pistol
     /Game/FPS/UI/Thumbs/T_Thumb_Vest
     /Game/FPS/UI/Thumbs/T_Thumb_Mag
     /Game/FPS/UI/Thumbs/T_Thumb_Helmet
4. FPS|Thumbnails|MeshRefs 只是对照网格路径，运行时不加载。

----------------------------------------------------------------
网格 → PNG → Texture（推荐，一次烘焙）
----------------------------------------------------------------
对照表（默认）：
  RAR   SK_RAR_AssaultRifle
        → T_Thumb_RAR
  手枪  SK_Pistol_Default_Combined
        → T_Thumb_Pistol
  背心  SKM_Bomber_Vest
        → T_Thumb_Vest
  弹匣  SM_RAR_AssaultRifle_Magazine_Default_Full
        → T_Thumb_Mag
  头盔  （你选的头盔 mesh）
        → T_Thumb_Helmet

方法 A：Perspective 视口截图（最简单）
1. 空关卡，放一个 Directional Light。
2. 拖入对应 StaticMesh / SkeletalMesh。
3. 透视视口调成侧视（枪常见 Yaw 90），背景清干净。
4. 视口右上角下拉 → High Resolution Screenshot（或 Win+Shift+S 裁切）。
5. PNG 丢进 Content/FPS/UI/Thumbs/，命名 T_Thumb_*.png，Import。
6. 打开 Texture：Texture Group = UI；Compression = UserInterface2D（或 RGBA）；
   sRGB 勾上；Mip Gen 可 NoMipmaps。

方法 B：用旧拍照台只拍一次再存盘（编辑器里，不进正式 UI）
1. PIE 临时关卡里 Spawn Mesh Preview Capture → Show Soft Path → 得到 RT。
2. Content Browser 里新建 TextureRenderTarget，或用「Render Target → Texture」
   （部分版本：右键 RT → Create Static Texture）。
3. 把生成的 Texture2D 挪到 Content/FPS/UI/Thumbs/ 并改名。
4. 正式 WBP 只用 Texture，不要再 Spawn Capture。

方法 C：外部 DCC（Blender / 截图工具）
侧视渲染透明底 PNG → Import 同上。

----------------------------------------------------------------
换装时
----------------------------------------------------------------
换枪/甲：只改 Soft Texture 指针，再调 RefreshAllThumbnails 或
ApplyTextureToImage。不要再调 Preview Soft Path To Image。
