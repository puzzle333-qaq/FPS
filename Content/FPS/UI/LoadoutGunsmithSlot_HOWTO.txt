WBP_Loadout → Gunsmith 按槽位过滤
================================

做什么
------
点 Loadout 里主武器行 → 打开 WBP_Gunsmith，武器列表只有长枪 (EWeaponKind::LongGun)。
点手枪行 → 只有手枪 (EWeaponKind::Pistol)。
Gunsmith 的 Back 会关掉改枪台回到 Loadout。

前提
----
1. WBP_Loadout 父类 = LoadoutMeshThumbnails（C++）。
2. WBP_Gunsmith 父类 = GunsmithScreen（C++）。
3. MainMenuPlayerController（或当前 PC）上有 GunsmithComponent，且 AvailableWeapons 填了可选枪。
4. 每把枪的 CDO 上 WeaponKind 设对（长枪 LongGun / 手枪 Pistol）。

按钮命名（任选一个，Is Variable 勾上）
--------------------------------------
主武器：Btn_MainWeapon 或 Button_MainWeapon 或 MainWeaponButton
手枪：  Btn_Pistol 或 Button_Pistol 或 PistolButton 或 Btn_Sidearm

名字对不上时，C++ 会在 WidgetTree 里按名字模糊搜索；Output Log 有
  [Loadout] Bound MainWeapon button: ...
找不到会 Warning。

可选 Class Defaults（WBP_Loadout）
----------------------------------
- GunsmithWidgetClass：默认 /Game/FPS/UI/WBP_Gunsmith
- GunsmithZOrder：默认 50

测
--
主菜单打开 Loadout → 点主武器行 → Gunsmith 列表应只有步枪类。
点手枪行 → 只有手枪。Back 关掉。

API（给蓝图/别的 UI）
--------------------
LoadoutMeshThumbnails::OpenGunsmithForKind(LongGun|Pistol)
GunsmithScreen::OpenForKind / ClearKindFilter / OnClosed
