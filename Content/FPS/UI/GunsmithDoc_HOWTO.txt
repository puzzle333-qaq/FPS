[GunsmithDoc] 对照《UE5 Gunsmith 枪械改装预览系统开发文档》P0 的实现说明
备份: Saved\CodeBackup_20261030_235819_GunsmithDoc

== 对应关系（复用现有，不新建一套）==
BP_GunPreviewActor   -> ALoadoutPreviewRig（SceneCapture+RT+灯，由 UGunsmithComponent 本地生成）
Weapon.bIsPreview    -> AWeapon::bIsPreview（新增，ExposeOnSpawn）
InitializePreview    -> UGunsmithComponent::SetPreviewWeapon（现为 Deferred Spawn，BeginPlay 前置 bIsPreview）
UpdateAttachmentVisual / UpdatePreviewAttachment -> AWeapon::EquipAttachment / RemoveAttachment（经 EquipPreview / RemovePreview）
PreviewLoadout vs CurrentLoadout -> 预览枪当前配件 vs CommittedAttachments 快照
确认 -> ConfirmPreview（= SaveCurrent 存 GameInstance+存档；进局由 PlayerController 发服务器校验）
取消 -> CancelPreview（回到打开时/上次确认的配件，正式配置不变）
ClearPreview -> 关界面 NativeDestruct 自动调用，销毁预览枪、停止捕获
WBP_Gunsmith -> UGunsmithScreen（父类）

== 预览隔离（bIsPreview=true）==
不复制、关碰撞、不 Tick；Local_Fire / Auth_Fire / PlayMagazineReload 直接返回。默认配件外观照常初始化。

== WBP 里要做的 ==
1. WBP_Gunsmith 父类 = GunsmithScreen。
2. 可选新增按钮：Button_Confirm（提交并关闭）、Button_Cancel（丢弃并关闭）。
   Back 按钮现在等同取消；Button_Save / Button_Equip 仍是提交但不关闭。
3. 蓝图可用：HasUnconfirmedChanges()（显示“未保存”提示）、ConfirmAndClose()、CancelAndClose()。
4. 中间 Image 名 Image_Preview（或 PreviewImage 等），槽位按钮/列表沿用原来那套。

== 测法 ==
Loadout 点主武器 -> 换个瞄具 -> 点取消/Back -> 再进，应是原配件；
换瞄具 -> 点确认 -> 再进，应保留；进局枪上也是新配件。

== 与文档的差距（未做，按文档属 P1/P2 或可选）==
- 文档的 M_GunPreview_UI 材质：没建，直接把 RT 作 Image 笔刷，效果相同。
- 文档的 EAttachmentSlot 枚举 / ST_AttachmentVisualData：项目用 GameplayTag 槽位 + UAttachmentData，已覆盖，不重复建。
- RT 尺寸默认 1024x576（文档建议先 1280x720），可在 GunsmithComponent 上改 PreviewWidth/Height。
- 预览用正交相机，文档写透视 FOV40；要透视需改 LoadoutPreviewRig。
- Show Only List：预览台放在 Z=-100000 远处，未显式 ShowOnly（如串景再加）。
- 鼠标旋转/缩放/对焦槽位、槽位标签跟随 Socket：已有（文档里是 P1/P2）。
- 配件安装动画、检视动画：未做。
