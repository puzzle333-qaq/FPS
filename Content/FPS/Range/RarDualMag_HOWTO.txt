RAR tactical dual magazine (safe) — 2026-10-28
=============================================

Root cause
----------
1. Infima original arm montage AM_RAR_FP_PCH_AssaultRifle_Reload has
   BP_IG_AN_Magazine_Reserve_Set_Visiblity (Set Reserve Magazine Visibility).
   Project copies AM_RAR_Reload / AM_RAR_Reload_Empty do NOT — only sound/camera notifies.
2. C++ already spawned a hidden SM on SOCKET_Magazine_Reserve, but SetMeshVisibility
   parent SetHiddenInGame(..., propagate) + HideReserveMagazines kept stomping it
   during reload attach/refresh, so only SOCKET_Magazine (one mag) stayed visible.
3. Prior RarMag "fix" also replaced WEP Montage_Play with DefaultSlot
   PlaySlotAnimationAsDynamicMontage — that froze magazine bones. DO NOT repeat.

Safe fix (this backup)
----------------------
- PlayMagazineReload: set bReloadReserveMagVisible, force-show main + reserve
  (spawn ReserveMag_1P if missing). No WEP playback changes.
- SetMeshVisibility: while flag set, re-show reserve after parent propagate.
- FinishMagazineReloadVisuals: clear flag + hide; called from OnReloadMontageEnded,
  OnObservedReloadMontageEnded, StopReloadMontages.
- PlayReloadSequences(1P) also calls PlayMagazineReload.
- PlayWeaponMontageOrSequence UNCHANGED (still Anim->Montage_Play).
