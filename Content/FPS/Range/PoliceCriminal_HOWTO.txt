# 警匪战术 / 剿匪 — PIE 测试说明

## 启用 GameMode
1. 打开靶场或测试图（如 Lvl_Range）。
2. World Settings → GameMode Override → 选 **PoliceCriminalGameMode**（C++）。
   或做蓝图子类 BP_PoliceCriminalGameMode（父类 PoliceCriminalGameMode）再选它。
3. PlayerStart：警察用 Tag `TeamA`，匪用 Tag `TeamB`（与团战一致）。没有 Tag 则用任意出生点。
4. 默认 MatchType = **Elimination（剿匪）**：10 分钟；全灭匪徒警察胜；时间到匪胜。一条命。

## 控制台流程
进 PIE 后按 `~`：

1. `PickFaction 0` — 警察（自动 FactionLook=警察）
   `PickFaction 1` — 匪（自动 FactionLook=匪）
2. 匪：`VanPick AK` / `Glock` / `Deagle` / `PCC`（固定配装，无改装；自动带刀）
3. 警：`ArmoryPick RAR` / `X24`（会带改枪台已存配件）；`Armor 0|1|2`；`Vision 0|1|2` 或 Alt+K 夜视
4. 布置阶段警察移动锁定；`SkipSetup` 跳过布置立刻突击
5. `SpawnTestHostage` — 身前生成人质占位（Tag=Hostage，F 跟随 stub，可受伤；解救完整规则后做）

## 参数（GameMode 默认）
- CriminalSetupDuration = 60
- AssaultDuration = 600（剿匪 10 分钟）
- MatchType：Elimination / HostageRescue（人质胜负后接）
