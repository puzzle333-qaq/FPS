## Movement speeds (tunable)

Base (ShooterPlayerController):
- RunSpeed = **220**
- SprintSpeed = **320**

Modifiers (`AShooterCharacter::GetArmorSpeedMultiplier`):
- Police Light armor: **×1.00** (no slow; torso damage reduced)
- Police Heavy armor: **×0.78** (`HeavyArmorMoveSpeedMultiplier`)
- Criminal, no armor: **×1.12** (`UnarmoredCriminalSpeedMultiplier`)

Effective criminal unarmored: Run ≈ **246**, Sprint ≈ **358**.
Effective police light: Run **220**, Sprint **320**.
Effective police heavy: Run ≈ **172**, Sprint ≈ **250**.

## Key 3 throwable cycle

In `PoliceCriminal` mode, key **3** equips a throwable; pressing again cycles:
- Police: Flash → Grenade → Flash …
- Criminal: Molotov → Grenade → Molotov …

Flash washes vision (`AddVisionFlashWash`). Molotov is impact burn stand-in (radial damage); full fire pool later.
Optional editor polish: create BP children of `WeaponFlash` / `WeaponMolotov` under `Content/FPS/Weapon/Throwable/` and put those soft paths in GameMode Class Defaults.
