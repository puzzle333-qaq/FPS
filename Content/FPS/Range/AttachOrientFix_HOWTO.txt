AttachOrientFix — RAR 1P 左转90° + RAR/AK 3P FABRIK
=====================================================
Backup: Saved\CodeBackup_20261029_070024_AttachOrientFix

Root causes
-----------
1) RAR Mesh1P yaw ~90° left on Bandits FP arms:
   Grip sockets were copied from Ironbelly onto Bandits hand_r. Ironbelly vs
   Epic/Bandits hand_r bone axes differ; RAR (Weapon.type.rifle) Mesh1P then
   sits yawed left. Pistol/X24 not reported.

2) RAR/AK Mesh3P FABRIK wrong:
   PoliceAttachFix made GetFabrikWorldTransform fall back to Barrel/Muzzle/"Grip"
   and still set FABRIK_Alpha=1, so the left hand IK chased a bad effector.
   Also EnsureMesh3PGripSockets could remap a socket authored on a missing bone
   (e.g. weapon_r) onto hand_r while keeping that bone's RelRot — warping gun /
   LeftHandSocket world pose.

Fixes (.cpp only)
-----------------
- Weapon.cpp ApplyMeshAttachRelative: if 1P parent mesh path contains "Bandit"
  and WeaponType is Rifle, multiply relative rot by yaw +90°.
- Weapon.cpp GetFabrikWorldTransform: authored sockets only
  (FABRIK / LeftHandSocket / lefthand / IK_Hand_L / hand_l_socket). Removed
  Grip + Barrel/Muzzle approximations.
- ShooterCharacter.cpp EnsureMesh3PGripSockets + EnsureArms1PGripSockets Upsert:
  if source BoneName is missing on Bandits and is not hand_r, skip (no bad remap).
